# Stack

Define as tecnologias, versões e ferramentas adotadas na Vega.

[project/stack-01]: React 19 (`^19.3.1`) e TypeScript em modo `strict` com `noUncheckedIndexedAccess`.
[project/stack-02]: Estilos com CSS Modules (`*.module.css`), sem CSS-in-JS em tempo de execução.
[project/stack-03]: pnpm como gerenciador de pacotes, Node 22 ou superior.
[project/stack-04]: Testes com Vitest, jsdom, Testing Library e vitest-axe.
[project/stack-05]: Fontes Outfit e Inter variáveis incluídas no pacote, com a licença OFL ao lado (`fonts/OFL-*.txt`).
[project/stack-06]: Licença AGPL-3.0-only.
[project/stack-07]: Dependência de runtime nova só com justificativa registrada na tarefa.
[project/stack-08]: Build do pacote com Vite em modo biblioteca, gerando ESM, os tipos `.d.ts` e o CSS dos módulos.
