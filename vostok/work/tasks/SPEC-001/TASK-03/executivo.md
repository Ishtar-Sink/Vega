Trouxe para a Vega os botões (botão comum, botão só com ícone e botão com menu), que quase todos os outros componentes usam.
Os botões passaram a aceitar todos os atributos comuns de um botão, a funcionar com teclado e leitor de tela e a seguir a cor de marca trocada pelo produto sem recompilar.
Foram verificados por 36 testes automatizados, que cobrem acessibilidade, uso só com teclado e a troca de cor pela marca, além de uma captura de tela conferida pelo usuário.
Perfil padrão: as decisões de adaptação já estavam tomadas nos passos; o risco foi baixo, porque a entrega só criou componentes novos, sem alterar os existentes.
Desbloqueou os campos de cor, data e hora, os diálogos, os estados e, junto com os campos, os componentes de estrutura.
